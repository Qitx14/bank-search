# 需求文档

## 项目名称
题库搜题 App（Bank Search）

## 项目目标
为频繁参加工作的用户，提供一款 iPhone 上运行的搜题工具。用户批量拍摄试卷题目 → App 自动 OCR 识别 → 在题库中模糊匹配 → 展示完整答案。

## 用户画像
- 非技术用户，不懂编程
- 工作中需要频繁参加考试
- 考试题目源自固定题库
- 拥有 iPhone 和 Mac 电脑

## 核心需求

### NFR-1 部署方式
- PWA 网页应用，通过 Safari「添加到主屏幕」安装到 iPhone
- 免费，无需 Apple 开发者账号
- 无需上架 App Store

### NFR-2 离线使用
- 首次加载后可完全离线使用
- 所有数据（题库、历史记录）存储在手机本地
- OCR 识别在本地执行，不上传任何数据到服务器

### FR-1 题库管理
- 支持手机端直接导入 .xlsx 文件
- 自动识别三个 Sheet：单选题、多选题、判断题
- 解析列：题号、题目/题干、选项 A-D、答案
- 显示各题型题目数量统计

### FR-2 拍照搜题（核心）
- 支持拍照和从相册选取
- 批量上传，一次最多 9 张图片
- 本地 OCR 识别图片中的文字
- 模糊匹配题库中的题干
- 展示匹配结果含完整题目信息

### FR-3 结果展示
- 显示匹配的题目原文
- 显示正确答案（选项字母 + 具体内容）
- 显示匹配相似度
- 备选匹配结果供手动切换

### FR-4 搜索历史
- 自动保存每次搜索记录
- 可查看历史匹配结果
- 支持清除历史

## UI 要求
- 简洁直观，适合非技术用户
- 淡蓝色主题
- 底部导航栏：搜题 / 题库 / 历史
- 适配 iPhone 屏幕

## 技术约束
- 纯前端，无后端服务
- 所有处理在浏览器本地完成
- 部署在 GitHub Pages（免费静态托管）
- 中文 OCR 支持
