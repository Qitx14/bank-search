## 2026-08-04 下午：智能选项匹配 + 部署上线

### 智能选项匹配方案

**问题**：考试时选项顺序可能被打乱。题库中正确答案在 C，但考试图里正确内容可能被标为 A。

**方案**：
```
拍照 → AI OCR 返回 JSON {stem, options[{label,text}]}
     → stem 匹配题库 → 取 Question.answer 对应的选项内容
     → bigram 匹配该内容在 OCR options 中的位置
     → 显示：「应选 A」+ 正确内容
```

**改动文件**：
| 文件 | 改动 |
|------|------|
| `src/types/index.ts` | 新增 `OcrOption`、`OcrParsedResult`；`SearchResult` 加 `examAnswer`/`examAnswerContent` |
| `src/services/openai-ocr.ts` | Prompt 改为输出 JSON；`OcrItemResult` 加 `parsed` 字段；自动解析 JSON |
| `src/services/search.ts` | 新增 `matchOptionLabel()` — bigram 匹配题库答案内容定位图片选项字母 |
| `src/components/AnswerCard.tsx` | 考试模式：大字体「应选 X」+ 正确内容，不展示无关选项 |
| `src/pages/SearchPage.tsx` | 用 `parsed.stem` 搜索；匹配后调用 `matchOptionLabel` |

### 搜索结果优化

### 区域限制问题

- OpenRouter API 在国内被墙，手机需开梯子直连
- 开发环境：`import.meta.env.DEV` 判断 → 走 Vite 代理 `/api/openrouter/...`（电脑转发）
- 生产环境：直连 `https://openrouter.ai/api/v1/chat/completions`（需手机开梯子）

### 使用方式（手机端）

1. Safari 打开 → 添加到主屏幕（PWA 图标）
2. 手机开梯子（Shadowrocket 全局代理模式）
3. 设置页填入 OpenRouter API Key
4. 题库页导入 .xlsx 文件
5. 搜题页拍照 → 顶部答案汇总 + 每题详情
