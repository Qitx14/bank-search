## 踩坑记录（重要）

1. **WPS 文本框是表格**：《2023反假题库》里有一个 1×1 边框表格（文本框），单元格内有段落「错误」，mammoth 会转成 `<table><tr><td><p>错误</p>...`。若不过滤表格内段落，「错误」会被拼进 1082 题选项 B。修复：`extractParagraphLines` 排除 `p.closest('table')`。
2. **正文混入 XML 源码**：文档某段落正文是转义的 `<w:rPr>...` 源码文本，跳过规则：以 `<` 开头或含 `w:rPr`。
3. **验证脚本实体解码顺序**：必须先剥 HTML 标签再解码实体，否则垃圾段落里的 `&lt;w:rPr&gt;` 被解码后又被当标签剥掉、残留文字拼进选项。
4. **@types/mammoth 不存在**：mammoth 自带 `lib/index.d.ts`（`export =` 风格、面向 Node），但 package.json 无 types 字段，故自写浏览器入口声明。
