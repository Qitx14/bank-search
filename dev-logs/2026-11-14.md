# 开发日志 2026-11-14

## 今日主题

Phase 5：拍照搜题一图多题（v1.2）。旧版每张照片只识别一道题，升级为一张照片可含多道题（最多 5 道/张），AI 自动拆分、逐题搜索；结果页改为左右滑动分页 + 数字导航，类似市面搜题 App。

## 完成事项

### 1. AI OCR 一图多题识别（步骤 5.1 ✅）
- **修改** `src/services/openai-ocr.ts`
  - 提示词改为识别图中**全部**题目，返回 `{"questions":[{stem, options}, ...]}`，按从上到下排序，最多 5 道（`MAX_QUESTIONS_PER_IMAGE = 5`，控制 token 与识别质量）
  - `max_tokens` 800 → 3000（5 题题干+选项的输出量）
  - JSON 解析兼容三种格式：新 `{questions}` / 旧单题对象 / 裸数组；跳过空题、截断到 5 题
- **修改** `src/types/index.ts`：新增 `OcrParseResult`；`SearchResult` 增加 `questionIndex`（结果按「题」而非「图」组织）

### 2. 逐题搜索逻辑（步骤 5.2 ✅）
- **修改** `src/pages/SearchPage.tsx`（`handleStartSearch` 重构）
  - OCR 后按 (图, 题) 展开成题目列表，逐题 `searchQuestions()` + `matchOptionLabel()` 选项映射
  - 每题只保留匹配度最高的结果（展示取 `matches[0]`）
  - 单图识别失败记为一条错误结果，不阻塞其他图片；AI 未结构化时回退为原始文字单题（与旧版行为一致）
  - 匹配阶段复用进度条（「正在匹配题库 第 x/y 题...」）

### 3. 结果页分页滑动 UI（步骤 5.3 ✅）
- **新增** `src/components/QuestionPager.tsx`
  - CSS `scroll-snap-type: x mandatory` 原生左右滑动（**零新增依赖**），每页一道题
  - 页头「第 n / 共 N 题」+「第 X 张照片」；匹配成功显示 AnswerCard（完整题干 + 应选答案），未匹配/识别失败显示提示卡 + OCR 原文
  - 底部数字导航：34px 圆形按钮，当前页 Primary 高亮；题少居中、题多可横向滚动；`onScroll` 计算当前页联动高亮（0.15 吸附阈值防动画跳号），点击 `scrollTo` 平滑跳页，当前页数字自动 `scrollIntoView`
- **修改** `src/index.css`：新增 `.results-page`（100dvh 固定高度 flex 布局）/ `.results-summary`（答案汇总条，每 5 题一行）/ `.question-pager` 系列样式
- **修改** `src/components/AnswerCard.tsx`：增加 `fullStem` 属性（分页单题页展示完整题干）；判断题「应选 正确」不再重复显示两遍
- **修改** `src/components/OcrProgress.tsx`：进度数字去掉「张」单位（识别/匹配两阶段共用）
- **修改** `src/pages/SearchPage.tsx`：结果视图重写（汇总条 + QuestionPager + 重新搜题）；选图页文案更新（一张可含多道题、每张最多识别 5 道）

### xls 题库导入不识别（commit 4475eda）✅
- 用户新题库《反假货币及现金收付业务题库》（2026年版）.xls（WPS 老格式，3 个 Sheet）
- **根因**：`findColumn` 题干列模糊匹配时，「题目」别名先命中了「题**目解**析（选填）」列 → 解析列大多为空 → 1897+4493+2095 行只剩 17 道判断题被解析
- **修复**：
  - 题干列排除含「解析」「分析」的表头；别名「题干」优先于「题目」
  - 判断题答案归一化：A/√/对 → 正确；B/×/错 → 错误（与 docx 解析一致）
  - `xlsx-parser` 抽出 `parseExcelBuffer` 供 Node 脚本复用；新增 `scripts/inspect-xls.ts` 检查工具
- **验证**：5431 题全部解析（单选 1897 / 多选 1439 / 判断 2095；多选 sheet 第 1441 行后为 WPS 空行残留，属正常跳过）；旧 docx 题库 1162 题回归通过；已部署上线
